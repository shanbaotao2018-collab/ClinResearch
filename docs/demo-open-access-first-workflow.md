# 演示模式：开放全文优先工作流

## 适用范围

本模式是 `client_online` 部署下的默认工作流。PubMed、Europe PMC 检索和开放全文下载都由桌面客户端本地连接器完成；后端只保存项目、校验结果、全文缓存和审计记录。

它不替代正式系统综述的完整检索。正式综述不得因暂时没有开放全文而把科学上符合条件的研究直接排除。

## 自动执行链

1. 文献检索与综述 Agent 检索、导入并去重候选题录。
2. 它默认对全部去重题录逐篇执行全文预检，并按每批最多 5 篇调用客户端连接器。
3. 桌面本地 `literature_client` 为每篇调用 Europe PMC，验证 PMID、PMCID、HTTPS `fullTextXML` 与 XML `article` 结构。
4. 后端保存独立的全文状态，不改变 `include`、`exclude` 或 `human_review` 决定。
5. 标题摘要筛选建议会同时展示科学相关性和全文状态；研究者再确认最终纳入。
6. 证据抽取与系统评价 Agent 优先读取已经缓存的 `full_text_ready` 文档，不再重复网络下载。

## 全文状态

| 状态 | 含义 | 后续处理 |
|---|---|---|
| `full_text_ready` | 客户端已验证并缓存 Europe PMC 开放 XML | 可进入全文抽取与系统评价 |
| `pdf_needed` | 科学上可能符合，但需要研究者提供合法 PDF | 等待上传后再抽取 |
| `access_unavailable` | Europe PMC 未找到可用开放 XML | 演示时不优先；正式综述保留待获取 |
| `verification_failed` | PMID/DOI/URL 或 XML 结构校验失败 | 不得作为全文证据使用 |
| `not_checked` | 尚未执行预检 | 返回文献综述 Agent 预检 |

## 手工验证提示词

```text
我想研究心衰患者出院后接受结构化远程随访，是否改善再入院或自我管理。
请从零创建文献综述项目，完成检索与去重，再向我展示科学筛选建议与全文状态。
在我确认前不要保存纳入或排除决定。仅用于公开文献的软件方法学演示。
```

确认纳入后，切换到“证据抽取与系统评价”并输入：

```text
请继续处理综述项目 #<review_project_id>。优先使用文献综述阶段已经验证并缓存的全文，
完成基础证据抽取；在进入全文系统评价前通过 OpenCode 原生确认。没有 `full_text_ready` 或研究者 PDF 的文献只列入待补全文清单，不要做偏倚风险评价或 Meta 分析。
```
