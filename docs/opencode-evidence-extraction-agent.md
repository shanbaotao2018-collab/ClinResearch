# 文献筛选与证据提取 Agent 使用说明

## 它解决什么问题

它把“已初筛纳入”的文献整理成一张可审阅的证据表，而不是替你做最终系统评价结论。

它会记录每条信息来自哪里：只有题录、摘要，还是你提供的全文摘录。没有明确依据的字段会写成“未报告”，并进入人工复核清单。

## 使用前需要什么

1. 先用文献综述 Agent 建立并完成一个文献项目。
2. 项目中至少有一篇文献已经被研究者确认或记录为 `include`。
3. 从仓库根目录启动 OpenCode，并选择 `evidence-extraction-agent`。

## 你可以这样提问

```text
请对文献项目 32 做证据提取。重点整理研究设计、研究对象、样本量、干预或暴露、对照、结局和效应指标。没有出现在摘要中的内容请标记未报告，不要猜测。
```

## Agent 会做什么

1. 创建一次可追溯的提取运行。
2. 调用“临床研究信息提取”和“方法学提取”Skills。
3. 把每篇已纳入文献保存为结构化证据行。
4. 调用撤稿核查 Skill，并使用 PubMed 的公告类型查询记录检查时状态。
5. 导出 Markdown 或 JSON 证据表，同时附上实际 Skill 调用回执。

## 你需要理解的三个提示

- `evidence_basis`：信息来源层级。摘要并不等于全文；仅有题录信息时不能填写效应量。
- `not_flagged_at_check_time`：本次 PubMed 查询没有返回撤稿/更正/关注公告标记，不是永久安全证明。
- `needs_human_review`：任何证据行都需要研究者最终对照全文确认。
