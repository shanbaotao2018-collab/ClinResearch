# Project-Local Skills

This directory is intentionally generated from the curated subset of the upstream `vendor/medical-research-skills/` repository.

Populate it with:

```bash
bash scripts/opencode/sync-medical-research-skills.sh
```

OpenCode can discover project-local skills from `.agents/skills/*/SKILL.md`.

Do not hand-edit copied third-party skills here. Update the sync script or the upstream vendor snapshot instead.
