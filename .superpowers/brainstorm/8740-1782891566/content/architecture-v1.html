文献综述智能体 MVP：总体架构

推荐方案：Dify 作为 B/S 宿主，外接专业工具服务，采用编排型 Agent

总体分层
第 1 层

B/S 工作台宿主

Dify 应用界面、项目列表、任务入口、结果展示、权限控制

第 2 层

编排型 Agent 层

总控 Agent 负责调度 4 个子 Agent，控制流程、状态和人工确认节点

1. 选题拆解 / 检索式 Agent
2. 检索执行 Agent
3. 去重筛选 Agent
4. PRISMA 汇总 Agent
第 3 层

专业工具服务层

PubMed / Europe PMC、中文题录导入、ASReview 或 AiReview、PRISMA 统计服务

第 4 层

院内部署数据层

项目库、题录库、筛选决策、纳排理由、审计日志，全量留在私有环境

主流程

Step 1 研究者输入研究问题

Step 2 检索式 Agent 生成 PubMed 检索式

Step 3 人工确认后执行检索

Step 4 题录入库、去重、初筛

Step 5 记录纳排决策与理由

Step 6 自动生成 PRISMA 统计与图

Step 7 输出结果包与审计痕迹

必须保留的人机协同点

人工确认点 A 检索式执行前

人工确认点 B 标题摘要纳排时

人工确认点 C PRISMA 最终出图前

原因：第一版不是全自动科研代理，而是“可追溯、可复核”的科研工作台。
