文献综述智能体 MVP：工具层、数据流与系统边界

原则：专业能力尽量复用现成组件，项目状态与审计数据必须收口到你们自己的私有系统

推荐工具层
检索工具

PubMed / Europe PMC 接入

负责英文医学题录检索、摘要获取、元数据补全。

导入工具

RIS / NBIB / BibTeX / CSV 导入器

负责中文数据库题录文件导入，避免第一版直接碰授权接入难题。

筛选工具

ASReview 或 AiReview

负责标题摘要筛选建议、优先级排序、人工复核协助。

统计工具

PRISMA 统计与出图服务

负责根据规则流累计的计数生成标准结果。

后续阶段的 PDF 解析器

最小数据流

1. 用户输入研究问题，创建项目。

2. 检索式 Agent 生成查询式，保存版本。

3. 检索执行 Agent 调 PubMed / Europe PMC，结果入题录主表。

4. 用户可追加上传中文题录文件，统一入同一题录主表。

5. 规则流执行去重，生成唯一题录集。

6. 去重筛选 Agent 调筛选引擎，产出纳排建议。

7. 人工确认纳排后，规则流累计各阶段计数。

8. PRISMA 汇总 Agent 读取计数表，生成图和过程摘要。

三个必须坚持的约束

约束 1： 外部工具只能处理“任务”，不能成为项目事实来源；事实来源只能是你们自己的项目数据库。

约束 2： PRISMA 计数必须来自规则流累计，不能由 Agent 自己口述统计。

约束 3： 第一版不把全文 PDF、偏倚评价、综述写作揉进来，避免范围失控。
